# 🚀 Guía de Inicialización y Arquitectura Backend — EMCA System

Este documento contiene las instrucciones técnicas para configurar, inicializar y mantener el servidor backend (API REST) del proyecto **EMCA**.

---

## 📋 1. Requisitos Previos

Asegúrate de contar con las siguientes herramientas instaladas en tu entorno de desarrollo:

* **Node.js** (`v18.x` o superior)
* **Gestor de paquetes:** `npm` o `yarn`
* **Base de datos:** MySQL 8.0+
* **Herramientas de ejecución TypeScript:** `tsx` o `ts-node`

---

## 🛠️ 2. Estructura del Proyecto

El backend está desarrollado en **Node.js** con **Express** y **TypeScript**, implementando una arquitectura modular por capas:

```text
backend/ (o backent/)
├── src/
│   ├── config/              # Configuración de base de datos MySQL, variables y Multer
│   ├── controllers/         # Controladores de la lógica de negocio (20 módulos)
│   ├── dtos/                # Data Transfer Objects (DTOs) para transporte de datos
│   ├── routers/             # Definición y mapeo de rutas Express (/v1)
│   ├── services/            # Lógica de consultas y persistencia de datos
│   ├── uploads/             # Almacenamiento local de archivos multimedia
│   └── Index.ts (o app.ts)  # Punto de entrada principal de la aplicación
├── .env                     # Variables de entorno locales
├── package.json
└── tsconfig.json
⚙️ 3. Configuración del Entorno (.env)
Crea un archivo llamado .env en la raíz de la carpeta del backend con la siguiente estructura:

Fragmento de código
# Servidor
PORT=4000
NODE_ENV=development

# Base de Datos MySQL
DB_HOST=127.0.0.1
DB_USER=root
DB_PASSWORD=tu_contraseña
DB_NAME=emca_db
DB_PORT=3306

# URL Base para Recursos y Webhooks
API_BASE_URL=[http://127.0.0.1:4000/v1](http://127.0.0.1:4000/v1)
📦 4. Instalación de Dependencias
Abre la terminal en la carpeta del backend e instala los paquetes necesarios:

Bash
npm install
🚀 5. Comandos de Inicialización
Modo Desarrollo (con recarga automática mediante TSX)
Bash
npm run dev
# O ejecución directa de entrada:
npx tsx watch src/Index.ts
Modo Producción (Compilación a JS y Ejecución)
Bash
# 1. Compilar código TypeScript
npm run build

# 2. Iniciar servidor compilado
npm start
🗂️ 6. Controladores del Sistema (/src/controllers/)
A continuación se detalla la responsabilidad de cada controlador del sistema:

AdminController.ts: Gestión de funcionalidades administrativas globales.

auth.controller.ts: Autenticación, tokens de sesión y validaciones de seguridad.

AyudaController.ts: Centro de ayuda y tickets de soporte técnico.

bitacorasController.ts: Registro de auditoría e historial de acciones en el sistema.

bot.controller.ts: Recepción de webhooks de Meta y puente con el chatbot de WhatsApp.

ComprobanteController.ts: Generación y consulta de comprobantes de atención.

ConfiguracionController.ts: Ajustes de parámetros globales y estado de servicios.

contenPrincipalController.ts: Gestión del contenido visual del portal principal.

employeController.ts: Mantenimiento de empleados, roles y permisos de acceso.

ImagenesController.ts: Manejo de imágenes de interfaz y recursos del sistema.

informeController.ts: Generación de informes consolidados para la dirección.

LoginController.ts: Procesamiento de credenciales de inicio de sesión.

mainController.ts: Métricas operativas del Dashboard del sistema.

menuController.ts: Estructura de menús y permisos de navegación.

multimediaController.ts: Carga y descarga de evidencias (imágenes, PDFs, notas de voz).

PerfilController.ts: Consulta y actualización de datos de perfil (Asesor/Jefe).

RecuperacionController.ts: Flujo de recuperación de contraseña por correo.

reportesController.ts: Gestión de reportes de PQR recibidos desde WhatsApp.

respuestasController.ts: Envío de respuestas oficiales hacia el ciudadano.

SolicitudesController.ts: Administración de solicitudes, asignaciones y cambios de estado.

🌐 7. Rutas Principales de la API REST (/v1)
GET /v1/solicitudes — Lista de PQRS en cola y atención

POST /v1/solicitudes/:id/responder — Envío de respuesta y adjuntos desde el operador

GET /v1/employe — Listado de operadores y estado de atención

GET /v1/perfil — Consulta de datos de sesión y perfil

POST /v1/multimedia/upload — Recepción de archivos multimedia (Multer)

GET /v1/informes — Consolidado de reportes para el Panel del Jefe
